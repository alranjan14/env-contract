# Examples

Runnable reference projects. Each is self-contained — `cd` in, install, then run
`env-contract check`. The `.env.example` committed in each was generated by
`env-contract sync`, so you can see exactly what the tool produces.

| Example                            | Stack             | Shows                                            |
| ---------------------------------- | ----------------- | ------------------------------------------------ |
| [`express-api`](./express-api)     | Express + Zod     | Single-package `check`, `ignoreKeys` config      |
| [`nextjs-app`](./nextjs-app)       | Next.js + Zod     | `NEXT_PUBLIC_*` client/server vars, T3 recipe link |
| [`turborepo`](./turborepo)         | pnpm + Turborepo  | `--workspace` across multiple packages           |

```bash
cd examples/express-api
npm install
npm run env:check     # exits 0 when in sync, 1 on drift, 2 on a config/runtime error
```

> These projects are **not** part of the published npm package, and they are not
> in this repo's pnpm workspace — they're standalone references you can copy into
> your own project. They depend on `env-contract` by its published version range.

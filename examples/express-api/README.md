# Example: Express + Zod

A minimal Express API whose environment contract is kept honest by `env-contract`.

- [`src/env.ts`](src/env.ts) — the Zod schema (the source of truth).
- [`src/server.ts`](src/server.ts) — uses `process.env.*`; `scan` cross-checks these against the schema.
- [`env-contract.config.ts`](env-contract.config.ts) — ignores `NODE_ENV`.
- [`.env.example`](.env.example) — generated by `env-contract sync` (managed block).

## Try it

```bash
npm install
npm run env:check     # CI-friendly: fails on drift (exit 1) or errors (exit 2)
npm run env:sync      # regenerate .env.example from the schema
```

To see drift detection in action, add `process.env.STRIPE_KEY` to `src/server.ts`
without adding it to `src/env.ts`, then run `npm run env:check` — it exits `1` and
points at the file and line.
